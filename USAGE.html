社群發文工具 使用說明

從一台桌機,把同一篇貼文同時發到 Instagram、Threads、YouTube。所有 API 憑證只存在你電腦的 OS 金鑰庫,絕不上傳。

1. 這個工具能做什麼

把同一篇文(文字 / 圖片 / 影片)一次發到下列平台:

Instagram

單圖、輪播(最多 10 張)、Reels 短影音。圖片/影片會自動透過 Cloudinary 中轉。

Threads

純文字、圖片、輪播、影片。圖片/影片會自動透過 Cloudinary 中轉。

YouTube

影片上傳,可設定標題、描述、公開/不公開/私人。不需要 Cloudinary。

TikTok 未實作

介面上保留,但目前未啟用。等官方 API 審核通過後會開放。

注意:Facebook 粉專目前因 Meta 的 pages_manage_posts 權限需要送官方審核,本工具暫時不提供 FB 發布。介面上的 FB 也已隱藏。

2. 一次性準備:申請 API 憑證

你需要自己去各平台的開發者後台申請一組憑證。本工具只負責使用,不代理註冊。

平台你需要拿到的東西
Instagram / Threads 一個 Meta App,拿到 App ID + App Secret(或直接取得 long-lived access token 也可以手動貼)
YouTube Google Cloud OAuth Client(桌面應用程式類型),拿到 Client ID + Client Secret
Cloudinary Cloudinary 帳號(免費版即可),拿到 Cloud name + API key + API secret
Redirect URI:每張卡片上方都會顯示一個 Redirect URI,把那串網址貼到對應開發者後台的「OAuth 重新導向 URI 白名單」,不加會被擋。

各平台後台的位置在「設定」頁的每張卡片內都有提示文字(例如:Meta 後台 → Use Cases → Instagram API with Instagram Login → Customize → Settings → User Token Generator)。

3. 設定頁怎麼填

第一次打開先到「設定」分頁,把要用的平台逐一連線。

Instagram / Threads

  1. 輸入 App ID / App Secret → 按「透過 OAuth 連線」。
  2. 或照畫面提示,直接到 Meta 後台複製 long-lived token,貼到欄位。
  3. Token 預設 60 天,工具會在你每次開啟 App 時自動延長。只要你別斷線超過 60 天就會一直續命。

YouTube

  1. 輸入 Client ID / Client Secret → 按「透過 OAuth 連線」。
  2. 瀏覽器會開啟 Google 授權頁,授權完成回來。
  3. 拿到的是 refresh token,理論上永久有效;若超過 6 個月沒用會失效,重新授權即可。

Cloudinary

  1. 填 Cloud name + API key + API secret(三者要是同一個 Cloudinary 帳號)。
  2. 按「驗證 Cloudinary」會去查你的剩餘額度。看到 plan=Free · 已用 X/25 點 就 OK。
危險區:設定頁最下面的「清除所有憑證」會把全部憑證刪光,動作不可逆。

4. 立即發文

圖文模式

  1. 切到「發布」分頁的「圖文」。
  2. 在「說明文字」打文案。
  3. 按「+ 加入圖片」選一張或多張(最多 10 張),可以拖曳調順序。
  4. 勾選要發的平台(IG / Threads)。
  5. 按「發布」。

影片模式

  1. 切到「影片」分頁。
  2. 填「影片標題」(YouTube 必填) + 「影片說明」。
  3. 按「+ 加入影片」選一支 mp4 / mov / m4v。
  4. 勾選要發的平台(IG / Threads / YouTube)。
  5. 按「發布」。

按下發布之後

  • 如果有 IG / Threads,圖片/影片會先自動上傳到你的 Cloudinary(它們的 API 只接受公開網址)。
  • 依序呼叫每個平台 API。
  • 不論發布成功或失敗,剛剛上傳到 Cloudinary 的檔案都會立刻被刪掉,不會累積占用空間。
  • 每個平台的成功/失敗狀態會顯示在頁面底部「結果」區。

5. 排程發文

要在未來某個時間自動發,用排程。

建立排程

  1. 切到「排程」分頁,選「圖文排程」或「影片排程」,按「+ 新增」。
  2. 跟發文頁一樣填內容、選平台。
  3. 在「排程時間」選未來時間(至少 60 秒之後)。
  4. 按「排程發布」。
⚠ 排程的重要限制:
  • 排程只記錄你選的「本機檔案路徑」,到時間才會去讀檔案上傳/發送。
  • 排程建立後,圖片/影片請留在原本的位置,不要移動、改名、刪除。
  • 外接硬碟或隨身碟上的檔案,如果排程到時裝置沒接,會找不到檔案而失敗。
  • 排程到時電腦必須是開機 + App 在執行(可最小化到系統匣)才會自動發。關掉 App 就不會發。
  • 不確定能不能保留檔案,建議排程前先把媒體複製到一個固定資料夾再選。

排程怎麼跑

  • App 開著時每 30 秒檢查一次,時間到的排程會在背景發出去。
  • 觸發誤差通常落在 30 秒內。
  • 觸發時的流程跟立即發布一樣:上傳到 Cloudinary → 發各平台 → 刪 Cloudinary。

編輯與刪除

  • 等待中、失敗狀態的排程可以編輯或刪除。
  • 發布中、已完成的排程只能刪除,不能改。
狀態意思
等待中還沒到時間
發布中正在跑 API
已完成全部平台都成功
失敗至少一個平台失敗,展開看「發布結果」

6. 常見問題

我只想用 YouTube,要設 Cloudinary 嗎?

不用。Cloudinary 只在 IG / Threads 這幾個流程才會被呼叫。純 YouTube 上傳完全不會碰到 Cloudinary。

為什麼 IG / Threads 一律公開?

IG / Threads 的官方 API 不支援私人貼文,這是平台限制,不是工具的選擇。

Cloudinary 免費額度會被吃光嗎?

不會。每次發完(不論成敗)工具會立刻刪掉剛剛上傳的檔案,不會累積占用空間或流量。免費方案每月 25 點通常用不完。

YouTube 一天能上傳幾部?

預設 Google 配額是 10,000 units / 天,每支影片消耗約 1,600,所以大約一天 6 部就到上限。要更多要去 Google Cloud Console 申請額度提升。

Token 過期怎麼辦?

  • IG / Threads:60 天 token,App 開啟時自動 refresh。超過 60 天沒開過 → 失效,重新 OAuth 授權即可。
  • YouTube:refresh token 久未使用會失效,重新授權即可。

排程準嗎?

最小提前量 60 秒,實際觸發誤差落在 30 秒內(輪詢間隔)。但前提是 App 開著。

「失敗」是哪邊失敗?

排程清單展開「發布結果」會列出每個平台各自的狀態,失敗的會帶錯誤訊息。發文頁也會在底部「結果」區塊顯示。

憑證會被上傳到雲端嗎?

不會。所有 token、secret 都只存在你 OS 的金鑰庫(macOS Keychain / Windows Credential Manager / Linux Secret Service),工具本身不連任何後端伺服器。

7. 故障排除

Cloudinary 401 cloud_name mismatch

你 API key 跟 cloud name 不是同個帳號的。回 Cloudinary dashboard 比對三個欄位,要全部來自同一個帳號的 Settings → API Keys。

發布按鈕變灰

檢查這幾項:

  • 有沒有勾平台
  • IG 圖文模式有沒有附圖(IG 不能純文字)
  • 影片模式有沒有附影片
  • YouTube 有沒有填標題

OAuth 卡在「等待瀏覽器」

  • 點那行字本身會取消。
  • 確認瀏覽器有打開、有授權完成。
  • 確認本機 redirect 埠沒有被防火牆擋。

排程到時間沒發

  • 確認 App 那時候有在跑(沒被完全關掉)。
  • 確認檔案沒被移動、改名、刪除。
  • 展開該筆排程看「發布結果」是否有具體錯誤訊息。

IG / Threads token 失效

到「設定」頁該卡片重新做一次 OAuth 連線,或重新貼一份 long-lived token。

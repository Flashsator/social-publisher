你有沒有過這種感覺?

寫好一篇想分享的內容,要發到 IG。

然後切到 Threads 再貼一次。

順便剪一段影片發到 YouTube。

同一張圖,選了三次。同一段文字,複製貼上三次。明明就是同一篇,卻要做三遍。

市面上不是沒有解法 ─ Buffer、Hootsuite、Later 都能跨平台發文。但你打開定價頁一看:

  • 免費版只給 1 個帳號,連 IG + Threads 都不能一起綁
  • 付費版一個月 15~99 美金,只為了省 30 秒複製貼上
  • 而且你要把帳號的登入權限交給他們的伺服器保管

付月費也就算了,你的帳號 token 存在別人公司伺服器,哪天他們被駭、倒閉、改條款,你的自動化就斷了。

所以我做了一個相反的東西

Social Publisher 是一個直接裝在你 Windows 電腦上的桌機 App。

沒有月費。沒有雲端帳號。憑證只存在你自己電腦的密碼管理員裡(跟 Chrome 幫你記密碼是同個地方)。

你發文的時候,程式直接從你的電腦呼叫 IG、Threads、YouTube 官方,中間沒有任何別人的伺服器。

一句話總結:

把市面上要付錢的跨平台發文工具,做成免費裝在自己電腦的版本。資料 100% 在自己手上。

排程未來發文

晚上有靈感,想規劃接下來一週的貼文?選好日期時間,程式時間到了會自動發。

免費版本沒有「上限幾則」的限制。你想排 100 則排 100 則。

⚠ 但有一個誠實的限制要先講:

因為這是免費的桌機程式,不是雲端服務,所以排程到的時間點,你的電腦必須開機,App 也要在跑(可以最小化到工作列右下角)。

如果你的需求是「我關電腦也要能發文」,那要找付費的雲端 SaaS。但如果你的電腦本來就一直開著,這完全不是問題。

密碼跟憑證都鎖在自己電腦

所有 IG / Threads / YouTube 的登入授權,都直接存進 Windows 自己的「認證管理員」。這是微軟內建、跟 Chrome 存密碼同一個機制的安全儲存空間。

程式本身不會連任何陌生的伺服器。你打開網路監控可以驗證:它只會連到 IG、Threads、YouTube 三家官方的網址,以及你自己的圖片中轉服務 Cloudinary(下面會解釋)。

圖片自動中轉、自動清空

這部分稍微技術一點,但你不用記細節 ─ 只需要知道:

  • IG 跟 Threads 的官方規則不接受你直接上傳檔案,只接受「網路上的圖片連結」
  • 所以程式會自動幫你把圖丟到 Cloudinary(免費的圖床)
  • 發完之後,立刻把圖從 Cloudinary 刪掉

你的 Cloudinary 免費額度永遠不會被吃光,因為發完即焚。整個過程你完全不用手動操作。

這套適合誰用?

✓ 適合你,如果:

  • 你經營自己的社群,IG + Threads + YouTube 至少兩個
  • 不想為了省 30 秒貼文付月費
  • 在意「我的帳號 token 被誰拿著」
  • 電腦本來就常開著
  • 願意花 30 分鐘做一次設定(只要做一次,以後永遠不用再弄)

✗ 不適合你,如果:

  • 你要管理客戶的幾十個帳號(請用 Buffer / Hootsuite)
  • 你主要用手機,電腦不常開
  • 完全不想碰任何技術設定
  • 你需要發 TikTok(目前因為平台政策還沒實作)

三步驟開始用

1

下載安裝

到 GitHub Release 頁下載安裝包(setup.exe),或下載免安裝版(portable.zip)解壓即用。

2

申請一次帳號(約 30 分鐘)

到 Meta、Google、Cloudinary 三個地方各申請一組免費的開發者帳號,把 ID 跟密鑰貼進 App 裡。App 內每個欄位都有提示告訴你「去哪裡拿」,跟著做就好。一輩子只要做這一次。

3

開始發文

打字、選圖、勾平台、按發布。以後每次都是這四個動作。

常見問題

Q. 真的完全免費?有沒有隱藏收費?

沒有。MIT 授權,程式碼公開在 GitHub,沒有任何付費版、進階版、訂閱制。我不靠這個賺錢。

Q. 為什麼要免費做這個?

原本就是我自己要用的工具。做完發現好用,丟出來給有同樣痛的人用,大家都省事。

Q. 安全嗎?程式會不會偷偷上傳我的東西?

程式碼完全公開在 GitHub。你可以自己看(或請工程師朋友幫你看),所有網路連線只會到 IG、Threads、YouTube、Cloudinary 四個地方,沒有任何「往我的伺服器送資料」的程式碼,因為我根本沒有伺服器。

Q. 我電腦關機時排程怎麼辦?

不會發。這是免費桌機工具的硬限制。如果你需要 24 小時都能自動發,要付費用 SaaS。

Q. 為什麼沒有 TikTok?

TikTok 官方規定:沒通過審查的工具,發出來的影片「只有自己看得到」。對「發給粉絲」這個目的來說沒意義,所以暫時不做。等政策放寬會補上。

Q. 之後會出 Mac / Linux 版嗎?

程式底層支援跨平台,但我手邊只有 Windows 機器可以測試。等有需求或有人幫忙測,就會出。

Q. 萬一出 bug 找誰?

到 GitHub Issues 開 issue,我看到會盡量回。

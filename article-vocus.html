每次想同時發 IG + Threads + YouTube,就要切三個 App、複製貼上三次、上傳三遍。市面上的工具不是月費爆貴,就是要把你的 token 交給某個雲端後端。所以我自己寫了一個,程式碼開源、完全免費、所有憑證只存在你電腦裡。

為什麼又要做一個發文工具?

現在的市場上,跨平台發文工具不是沒有。Buffer、Hootsuite、Later、SocialBee… 但它們有一個共同點:你要把社群帳號的存取權交給他們的伺服器,然後每個月付錢。

對品牌行銷團隊來說,這沒問題。但對「一個人經營兩三個社群帳號」的個人創作者來說,這個交易很不划算:

  • 每月 $15 ~ $99 美元的訂閱費,只為了省下 30 秒的複製貼上
  • 你的 API token 存在一個你不認識的雲端伺服器上,出事誰賠?
  • 免費版幾乎都只給 IG 一個帳號,要多帳號就要升級
  • 對方倒了、被買走、改條款 — 你的自動化就斷了

所以我做了一個相反方向的東西:純桌機程式,你的電腦就是後端,憑證存在 Windows 自己的金鑰庫,沒有任何雲端帳號要註冊。發文時直接從你的電腦呼叫 Meta、Google 的官方 API,中間不經過第三方。

它能做什麼

1. 同時發到多個平台

打一次字、選一次圖,勾選要發的平台,按發布。剩下交給程式:

  • Instagram — 單圖、輪播(最多 10 張)、Reels 短影音
  • Threads — 純文字、圖片、影片、輪播
  • YouTube — 影片上傳,可設標題、描述、公開/不公開/私人

每個平台的 API 規則不一樣(IG 圖片要公開 URL、YouTube 要從本機上傳…),這些細節程式會幫你處理。

[這裡建議放發文頁的截圖,顯示多平台勾選 + 圖片預覽]

2. 排程發文

設未來時間,排程到了會自動發。最常用的情境是:晚上一次規劃好下週的所有貼文,週一到週五自動發。

⚠ 排程的真實限制要先講清楚:

因為這是純本地工具,沒有雲端代你發文。所以:

  • 排程到時,你的電腦必須開機 + App 在跑(可以最小化到系統匣)
  • 排程的圖片/影片不能移動、改名、刪除,不然到時找不到檔案

這是跟 SaaS 工具最大的差別。如果你的需求是「我關電腦也要能發文」,那這套不適合你。

3. 憑證 100% 留在你電腦

所有 API token、App Secret 都直接存在 Windows Credential Manager(macOS 對應 Keychain、Linux 對應 Secret Service)。這是 OS 內建的安全儲存空間,跟 Chrome 存密碼是同一個機制。

程式本身不連任何後端伺服器。打開網路監控你會看到:

  • 連線到 graph.instagram.com / graph.threads.net(IG / Threads API)
  • 連線到 googleapis.com(YouTube API)
  • 連線到 api.cloudinary.com(你自己的 Cloudinary 帳號,中轉媒體用)

沒了。沒有任何「往我的伺服器送 telemetry」的請求,因為根本沒有我的伺服器。

4. Token 自動續命

IG / Threads 的長效 token 預設 60 天會過期,要手動 refresh。這個程式會在你每次開啟 App 時自動偷偷做 refresh,只要你別斷線超過 60 天,token 就會一直續下去,你不用管。

5. 自動媒體中轉

IG 跟 Threads 的官方 API 不接受你本機檔案,只接受公開 URL。所以發圖文時,程式會:

  1. 自動把你選的圖/影片上傳到你自己的 Cloudinary 帳號(免費方案完全夠用)
  2. 用拿到的公開 URL 呼叫 IG / Threads API
  3. 不論成功或失敗,立刻把剛上傳的檔案從 Cloudinary 刪掉

所以你的 Cloudinary 額度永遠不會累積。發完即焚。

誰適合用?

誠實地說,這套工具有適合跟不適合的人:

✓ 適合你如果你是:

  • 單兵作戰的自媒體創作者,經營自己的 IG / Threads / YouTube
  • 不想為了一個簡單需求付月費,寧可花時間自己設定一次
  • 對「我的 token 被誰拿著」這件事在意
  • 每天電腦本來就會開,排程半夜發文也沒差
  • 願意自己去 Meta / Google 開發者後台申請 App(只要一次)

✗ 不適合你如果:

  • 需要管理客戶的數十個帳號(請用 Buffer / Hootsuite)
  • 你的工作流程是手機操作,電腦不常開
  • 不想碰任何技術設定(雖然只要一次,但要 30 分鐘左右)
  • 需要 TikTok(目前因為平台政策還沒實作)

前往下載 →

第一次執行 Windows 會跳 SmartScreen 警告(因為沒簽 code-signing 憑證,簽一張要 USD 99/年起跳,獨立開發者不太可能花這個錢)。點「更多資訊」→「仍要執行」即可。

Step 2 · 申請憑證

這是最花時間的部分,但一輩子只要做一次:

平台你要拿到的大約耗時
Meta App
(IG + Threads 共用)		 App ID + App Secret,或直接抓 long-lived token 10 分鐘
Google Cloud
(YouTube)		 OAuth Client(桌面類型)的 Client ID + Secret 5 分鐘
Cloudinary Cloud name + API key + API secret(免費方案) 3 分鐘

App 內每張卡片都有提示文字告訴你「去哪個後台、點哪幾個按鈕」,看著做就好。

Step 3 · 發文

打開「發布」分頁 → 圖文或影片模式 → 填內容 → 勾平台 → 按發布。

結束。下次只要重複 Step 3。

為什麼沒有 TikTok?

TikTok 的 Content Posting API 對未審核 App 的限制是只能 SELF_ONLY(只有自己看得到),其他人看不到。對「發文工具」這個用途來說沒有意義,所以介面目前標記「未實作」。等 App 通過審核後會解禁。

為什麼開源?

幾個理由:

  1. 透明度。「憑證不外洩」這種承諾,光是嘴巴講你怎麼信?程式碼開源你可以自己看,看 source code 就知道我有沒有偷偷上傳。
  2. 我做這個本來就是給自己用的,既然做出來了,放出來給有同樣需求的人用,大家都省事。
  3. 沒人付我錢做這件事,所以也沒有商業包袱。如果之後 Meta 改 API,有人來 PR 修 bug 也歡迎。

MIT 授權,意思是你可以拿去用、改、商用、重新發布,都行。我唯一的請求是:如果你覺得有用,在 GitHub 上點顆 ⭐ 讓我知道有人在用就好。

常見問題

Q. 我只想用 YouTube,要設 Cloudinary 嗎?

不用。Cloudinary 只在 IG / Threads 發圖文時才會被呼叫。純 YouTube 上傳不會碰到。

Q. Cloudinary 免費額度會不會被吃光?

不會。每次發完(不論成敗)工具會立刻刪掉剛上傳的檔案,額度不會累積。免費方案每月 25 點對一般使用者來說用不完。

Q. 為什麼 IG / Threads 一律公開?

官方 API 不支援私人貼文,這是平台限制,不是工具的選擇。

Q. YouTube 一天能上傳幾部?

預設 Google 配額每天 10,000 units,每支影片消耗 ~1,600,所以一天大約 6 部到上限。要更多要去 Google Cloud Console 申請額度提升。

Q. 排程到時電腦關機怎麼辦?

不會發。這是純本地工具最大的限制。如果你有「我關電腦也要發」的需求,要用 SaaS。

Q. 之後會上 Mac / Linux 嗎?

Tauri 本身跨平台,程式碼層面理論上可以直接編 Mac / Linux 版。但我手邊只有 Windows 機器測試,所以目前只發 Windows。等有需求(或有人來 PR)再說。
